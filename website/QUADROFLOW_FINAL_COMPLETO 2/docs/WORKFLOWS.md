# WORKFLOWS — QuadroFlow

## WF-01 — Compra e acesso

1. Usuário entra na Landing Page.
2. Clica em acesso.
3. Entra no grupo oficial do WhatsApp quando o link estiver configurado.
4. Recebe instruções de pagamento via Pix.
5. Após confirmação, recebe acesso ao QuadroFlow.

## WF-02 — Abrir e instalar

1. Usuário clica em **Abrir QuadroFlow**.
2. O aplicativo abre no navegador.
3. Se a instalação automática estiver disponível, aparece **Instalar QuadroFlow**.
4. Se não estiver, o aplicativo mostra orientação simples para o navegador.
5. Se o navegador não oferecer instalação, o usuário pode continuar usando pelo navegador.

## WF-03 — Criar tarefa

1. Clicar em adicionar post-it.
2. Informar cliente, título e texto.
3. Definir prioridade.
4. Adicionar URLs e arquivos, se necessário.
5. Salvar.
6. A tarefa recebe a cor do quadrante.

## WF-04 — Produção

1. Arrastar a tarefa entre quadrantes.
2. O sistema altera a etapa.
3. A cor é recalculada pelo quadrante de destino.
4. A ordem é persistida.

## WF-05 — Entrega

1. Mover para **Tarefa entregue**.
2. Registrar data/hora de entrega.
3. Após o período definido pela aplicação, arquivar em **Entregues**.
4. O item não deve ir automaticamente para a lixeira.

## WF-06 — Lixeira

1. Excluir tarefa.
2. Tarefa vai para a lixeira.
3. **Voltar** restaura a origem quando possível.
4. **Excluir** remove definitivamente.

## WF-07 — Backup

1. Abrir Backup/Restaurar.
2. Exportar arquivo de backup.
3. Guardar o arquivo em local seguro.
4. Para restaurar, selecionar o backup.
5. Confirmar substituição.
6. Restaurar dados e anexos.

## WF-08 — Atualização

1. Nova versão é publicada no mesmo endereço.
2. Service Worker identifica a nova versão.
3. O navegador atualiza o cache.
4. O usuário recarrega quando solicitado.
