# COMO USAR — QuadroFlow

## Para o usuário

### 1. Abra

Acesse o endereço recebido e clique em **Abrir QuadroFlow**.

### 2. Instale

Na primeira abertura, o QuadroFlow mostra a melhor opção disponível para o navegador.

Se aparecer **Instalar QuadroFlow**, clique e confirme.

Se não aparecer, siga a orientação mostrada pelo próprio QuadroFlow para o navegador utilizado.

Se o navegador não oferecer instalação como aplicativo, você ainda pode usar o QuadroFlow normalmente pelo navegador.

### 3. Crie tarefas

Use **Adicionar post-it** e informe:

- Cliente
- Título
- Texto
- Prioridade
- URLs
- Arquivos

### 4. Organize

Arraste as tarefas entre:

- Tarefas
- Iniciar as tarefas
- Tarefa em produção
- Tarefa resolvida
- Tarefa entregue

A cor da tarefa acompanha automaticamente o quadrante.

### 5. Encontre

Use o filtro universal para procurar informações da tarefa.

### 6. Entregue

Quando o trabalho sair da operação, mova a tarefa para **Tarefa entregue**.

### 7. Lixeira

Se excluir uma tarefa, abra a Lixeira para restaurá-la ou excluí-la definitivamente.

### 8. Backup

Faça backups periódicos. O backup é a cópia externa recomendada para proteger seu trabalho.

### 9. Impressão/PDF

Use a opção de impressão para gerar uma lista de execução do quadro.

## Importante

O QuadroFlow guarda os dados localmente no navegador/dispositivo. O uso offline depende de o aplicativo ter sido carregado e armazenado pelo navegador. Não desinstale/limpe os dados do navegador sem manter um backup atualizado.
