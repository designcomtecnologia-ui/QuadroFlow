# Checklist antes da primeira venda

- [ ] Publicar o PWA em HTTPS.
- [ ] Definir domínio oficial.
- [ ] Configurar o link real do grupo de WhatsApp no site comercial.
- [ ] Configurar o link real do download na página de download.
- [ ] Testar instalação no Chrome/Edge.
- [ ] Testar instalação no Safari/macOS quando aplicável.
- [ ] Testar criação, edição, arrastar, anexos, links e impressão.
- [ ] Testar backup e restauração.
- [ ] Testar funcionamento offline depois da primeira abertura.
- [ ] Confirmar o texto comercial/termos de uso e política de privacidade antes da venda.
- [ ] Manter uma cópia do pacote de cada versão publicada.
