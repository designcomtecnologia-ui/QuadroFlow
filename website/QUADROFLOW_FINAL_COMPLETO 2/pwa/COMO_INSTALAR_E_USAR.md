# QuadroFlow — como instalar e usar

## Para o cliente — versão super simples

### 1. Abra o link

Você receberá um link do QuadroFlow. Clique nele.

### 2. Instale

Quando aparecer **Instalar QuadroFlow**, clique.

Se o botão não aparecer dentro do aplicativo, procure o ícone de instalação na barra de endereço do Chrome/Edge ou abra o menu do navegador e escolha a opção de instalar/adicionar o aplicativo.

### 3. Pronto

Depois da instalação, abra o **QuadroFlow** pelo ícone do aplicativo.

Você não precisa instalar nenhum outro programa.

---

# Como usar

### Criar uma tarefa

1. Clique em **＋ Adicionar post-it**.
2. Preencha Cliente, Título e Texto.
3. Escolha a Prioridade.
4. Se precisar, adicione URLs e arquivos.
5. Salve.

### Organizar

Arraste o post-it para o quadrante desejado. A cor do post-it acompanha automaticamente o quadrante.

### Pesquisar

Clique em **Filtro** e digite uma palavra. O campo pesquisa tarefas, clientes, arquivos, URLs e outros dados disponíveis.

### Concluir / entregar

Mova a tarefa até **Tarefa entregue**. Depois do período definido pelo QuadroFlow, ela passa para **Tarefas entregues**.

### Lixeira

Use **Lixeira** para tarefas excluídas manualmente. Uma tarefa pode ser restaurada ou excluída definitivamente.

### Imprimir / PDF

Abra o menu ☰ → **Imprimir / PDF**. A impressão é preparada como checklist: quadrantes um abaixo do outro, tarefas em sequência, cores dos quadrantes e um quadrado `□` para marcar cada tarefa no papel.

### Salvar e Carregar

O QuadroFlow mantém os dados no armazenamento local do dispositivo. Use **Salvar** quando quiser criar uma cópia conforme a rotina definida para sua instalação.

## Atenção

Os dados desta versão são locais. Se você trocar de computador ou apagar os dados do navegador/site, eles não são transferidos automaticamente.
