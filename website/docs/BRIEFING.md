# BRIEFING — QuadroFlow

## 1. Visão

O **QuadroFlow** é uma aplicação visual para organização de tarefas. O trabalho é acompanhado por etapas, representadas por quadrantes, e cada tarefa é apresentada como um post-it com informações essenciais, prioridade, links e anexos.

A proposta central é:

> **Do que precisa ser feito ao que foi entregue.**

O produto é distribuído como PWA, com uso local no navegador/dispositivo e funcionamento offline após o carregamento e instalação adequados.

## 2. Público

- profissionais autônomos;
- designers e criativos;
- freelancers;
- pequenas equipes;
- prestadores de serviço;
- operações que precisam visualizar o trabalho sem uma plataforma complexa.

## 3. Princípios

1. Visual antes de burocrático.
2. Baixo atrito para criar e mover tarefas.
3. A etapa atual determina a cor da tarefa.
4. Arquivos e links ficam associados à tarefa.
5. Exclusões podem ser recuperadas pela lixeira.
6. Dados locais devem ser protegidos por backup.
7. O usuário leigo não deve precisar entender tecnologia para instalar e usar.

## 4. Fluxo do produto

**Landing → Acesso → WhatsApp/Pagamento → Download → Abrir QuadroFlow → Instalar → Usar**.

Os links comerciais podem permanecer como placeholders até a publicação definitiva.

## 6. Regra fundamental

A cor de um post-it é consequência do quadrante atual. A tarefa não deve manter uma cor independente que contradiga a etapa.
