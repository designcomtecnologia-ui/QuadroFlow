# QuadroFlow — como instalar e usar

## Para o cliente — versão simples

### 1. Abra o link
Você receberá um link do QuadroFlow. Clique nele.

### 2. Instale
Quando aparecer **Instalar QuadroFlow**, clique. Se o botão não aparecer, use o ícone de instalação do Chrome/Edge ou o menu do navegador.

### 3. Pronto
Depois da instalação, abra o **QuadroFlow** pelo ícone do aplicativo.

Você não precisa instalar outro programa para usar a versão PWA.

## Onde encontrar o ícone

### macOS
- Procure por **QuadroFlow** no Spotlight (`⌘ + Espaço`).
- No Chrome, aplicativos instalados como PWA costumam aparecer em `~/Applications/Chrome Apps.localized/`.
- O local exato pode variar conforme navegador e versão do macOS.

### Windows
- Abra **Iniciar** e pesquise por **QuadroFlow**.
- O Windows pode mostrar o aplicativo na lista de aplicativos instalados.
- O caminho interno pode variar conforme Chrome/Edge e não deve ser usado como referência de instalação.

### Linux
- Procure **QuadroFlow** no menu de aplicativos do sistema.
- Em ambientes baseados em Linux, atalhos de aplicativos Chromium costumam ficar em `~/.local/share/applications/`, mas o nome e o local podem variar.

### Se não encontrar
Use a pesquisa do próprio sistema operacional pelo nome **QuadroFlow**.

## Como usar

### Criar uma tarefa
1. Clique em **＋ Adicionar post-it**.
2. Preencha Cliente, Título e Texto.
3. Escolha a Prioridade.
4. Se precisar, adicione URLs e arquivos.
5. Salve.

### Organizar
Arraste o post-it para o quadrante desejado. A cor do post-it acompanha automaticamente o quadrante.

### Pesquisar
Clique em **Filtro** e digite uma palavra. O campo pesquisa tarefas, clientes, arquivos, URLs e outros dados disponíveis.

### Concluir / entregar
Mova a tarefa até **Tarefa entregue**. Depois do período definido pelo QuadroFlow, ela passa para **Tarefas entregues**.

### Lixeira
Use **Lixeira** para tarefas excluídas manualmente. Uma tarefa pode ser restaurada ou excluída definitivamente.

### Imprimir / PDF
Abra o menu ☰ → **Imprimir / PDF**.

### Backup
Use **Fazer backup** e **Restaurar backup** para preservar os dados locais.

## Atenção
Os dados desta versão são locais. Eles não são sincronizados automaticamente entre computadores.
